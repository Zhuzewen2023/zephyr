.. zephyr:board:: zwz_gd32f303c

Overview
********

The ZWZ GD32F303CBT6 board is built around the GigaDevice GD32F303CBT6
Arm Cortex-M4F MCU.

Console output is provided over SEGGER RTT (channel 0), read through the
J-Link/SWD connector.

Hardware
********

- GigaDevice GD32F303CBT6 (Arm Cortex-M4F, 128 KiB flash, 32 KiB SRAM)
- 8 MHz HXTAL
- SWD/J-Link debug connector

Supported Features
******************

SoC level support only: no on-board peripheral (GPIO, UART, ...) is
described yet.
